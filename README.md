# Mante Beach Resort Website

A plain HTML/CSS/JavaScript recreation of the supplied Mante Beach Resort screenshot.

## Files
- `index.html` — page structure and content
- `style.css` — layout, typography, spacing, and responsive behavior
- `script.js` — smooth in-page navigation and prefilled room booking email links
- `assets/` — image crops extracted from the supplied screenshot
- `website-prompt.md` — reusable prompt describing the design

## Run locally
Open `index.html` in a browser. No build tools or dependencies are required.

## Customize
- Update room names and rates in `index.html`.
- Replace the extracted low-resolution image crops in `assets/` with the original high-resolution photos/logo when available.
- Update the phone number and email in `index.html` if the resort's contact details change.
